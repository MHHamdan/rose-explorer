# ROSE explorer: how generative AI works, one knob at a time

**Website: https://mhhamdan.github.io/rose-explorer/** · **Live app: https://huggingface.co/spaces/MHamdan/rose-explorer**

Every generative model, from a VAE to a large language model to a text-to-image system, has to get around one
obstacle: the probability of the data is intractable. The **route** a model takes around it (compute it exactly,
bound it, or avoid it) fixes its training **objective**, its **sampler** and the **evaluations** it admits. This
repository teaches that chain in two complementary ways.

| | What it is | Start here |
|---|---|---|
| **Equation notebooks** | 11 chapters covering every equation of the ROSE survey of generative models. Each equation is explained twice, in plain words for a first encounter and as a refresher with assumptions and a derivation sketch, then **verified in code** (402 checks). Each chapter ends with key takeaways and self-check questions. | [`notebooks/`](notebooks/README.md), each opens in Colab |
| **Interactive explorer** | A Gradio app with seven demos: divergences, language-model decoding, GAN critics, Langevin sampling, diffusion samplers, post-training tilts, evaluation metrics. Every tab names the chapter that verifies it. | [the live Space](https://huggingface.co/spaces/MHamdan/rose-explorer), the website, or `python app/app.py` |

## Run it

```bash
pip install -r requirements.txt
python app/app.py                         # the explorer, at http://127.0.0.1:7860
jupyter lab notebooks/                    # or open any chapter in Colab from notebooks/README.md
python tools/check_notebooks.py --strict  # rebuild, execute and verify every notebook (about 5 minutes on a CPU)
```

## How it is built

- `notebooks/*.ipynb` are generated from `notebooks/src/chNN_*.py` (edit the module, not the notebook; see
  [`notebooks/src/AUTHORING.md`](notebooks/src/AUTHORING.md)). `data/equation_registry.json` maps every equation id
  (e.g. `EQ-M-007`) to its place in the paper; `tools/check_notebooks.py` fails if any id is uncovered.
- `app/` is self-contained and runs as the Hugging Face Space `MHamdan/rose-explorer`; `SPACE_URL` in
  `app/genai_explorer/links.py` makes the website embed it (leave it empty to show a static gallery instead).
- `site/index.html` is generated by `site/build_site.py` (previews by `site/make_previews.py`) and published by
  `.github/workflows/pages.yml`. CI (`.github/workflows/ci.yml`) executes every notebook on each push.

## Contributing

Corrections and clearer explanations are welcome. Open an issue quoting the equation id, or edit the chapter
module and run `python tools/check_notebooks.py --strict` before opening a pull request. A verification must call
`check(name, ok, detail)` and run on a CPU in seconds; never weaken a check to make it pass.
